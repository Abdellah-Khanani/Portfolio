    Reset the numbers →
    Resetting: GoatCounter's API has no way to delete anything, so this button opens their own purge page rather than pretending to do it from here. There you pick what to clear — leave the path empty to wipe everything. It cannot be undone.
    About the token: make it on your GoatCounter site under Settings → API tokens, ticking only Read statistics. It is kept in this browser alone, never in the site files, so publishing never carries it anywhere.

    Publish

    1. Download the file

    Your changes live in this browser until you publish them. This gives you the single file the site reads, ready to drop in.

    Put the file in the site folder as js/projects.js, replacing the old one, then upload the folder to Netlify.

    2. Or save straight to GitHub

    Once the site lives in a GitHub repository, this button writes the file there and your host republishes on its own — no files, no computer, works from your phone.

    About the token: create a fine-grained token limited to this one repository, with permission Contents: read and write. It is kept only in this browser. Anyone who unlocks your phone could use it, so do not add other permissions, and delete it on GitHub if you lose the device.
